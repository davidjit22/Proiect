👋 Despre proiect

Project Web Demo este un proiect web realizat cu ajutorul limbajului HTML, având ca scop învățarea și exersarea dezvoltării paginilor web.

Proiectul reprezintă primul pas în explorarea tehnologiilor web și a instrumentelor moderne de programare.

🎯 Obiective
📌 Învățarea structurii unui document HTML.
💻 Crearea unei pagini web simple.
🎨 Formatarea și organizarea conținutului.
🔧 Utilizarea Visual Studio Code.
🚀 Gestionarea versiunilor folosind Git și GitHub.
🛠️ Tehnologii utilizate
Tehnologie	Descriere
🟠 HTML5	Structura paginii web
🔵 VS Code	Editor de cod
🟠 Git	Controlul versiunilor
⚫ GitHub	Găzduirea proiectului

⚙️ Cum se utilizează proiectul?
Descarcă sau clonează proiectul.
Deschide folderul în Visual Studio Code.
Deschide fișierul index.html.
Rulează pagina în browser.
🌟 Funcționalități
Pagina web conține un titlu principal.
Afișează un mesaj de bun venit.
Utilizează elemente HTML de bază.
